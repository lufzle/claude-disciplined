# Security

This project is alpha software. Treat it as experimental.

## Reporting a vulnerability

Please **do not** open a public issue for security-sensitive reports.

- Use GitHub **Security Advisories** on this repository (Security → Report a vulnerability), or
- Email the maintainer listed in `Cargo.toml`.

Include a description of the issue, affected versions (git commit if possible), and a minimal reproduction when you can share one.

We will acknowledge reports and, for confirmed issues, publish a fix and advisory as soon as practical.
